GitHub Access Token

For the extension to function on your behalf on GitHub, please provide your access token.

  1. Go to GitHub Personal Access Tokens page while logged in to your GitHub account.
  2. Click on the "Generate new token" button located at the top-right corner of the page.
  3. Select the "Classic" option when prompted.
  4. GitHub will ask you to log in again using your password.
  5. In the "Note" field, enter a name for your token and set an expiration time (note: the extension will stop working once the token expires, but the token can always be renewed).
  6. Under "Select scopes", check the boxes for the "repo" scope (the first 6 checkboxes) as these are the only permissions needed for the extension to function properly.
